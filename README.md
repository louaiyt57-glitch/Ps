# بيكسل بت (PixelPet) 🧣

تطبيق أندرويد أصلي بلغة **Kotlin** (بدون أي مكتبات خارجية) يعرض شخصية بكسل/مكعبات صغيرة تطفو فوق جميع التطبيقات وتتحرك وتتفاعل معك، بـ **50 حركة وتفاعلاً** وفقاعات حوار عربية.

- الرسم عبر `Custom View` و`Canvas` فقط (خفيف وسريع، ~30 إطاراً/ثانية، ويتوقف عند إطفاء الشاشة).
- الظهور فوق التطبيقات: `SYSTEM_ALERT_WINDOW` + `TYPE_APPLICATION_OVERLAY` + خدمة أمامية (Foreground Service).
- يعمل على أندرويد 8.0 وحتى 15+ (`minSdk 26`، `targetSdk 35`).

## كيف يعمل اللمس بدون تعطيل بقية الشاشة؟

نافذة الـ Overlay **صغيرة وتحيط بالشخصية وفقاعة الحوار فقط** (وليست شفافة بكامل الشاشة). تتحرك الشخصية بتحديث `x` و`y` في `WindowManager.LayoutParams` عبر `updateViewLayout()`، فيبقى كل ما تحتها قابلاً للمس والاستخدام بشكل طبيعي. الأعلام المستخدمة: `FLAG_NOT_FOCUSABLE | FLAG_NOT_TOUCH_MODAL`.

| اللمس | النتيجة |
|---|---|
| **سحب** | تحريك الشخصية يدوياً (تُعلَّق في الهواء أثناء السحب) |
| **نقر** | إيقاظها إن كانت نائمة، أو تشغيل حركة عشوائية |
| **أزرار نعم / لا** | رد فعل مختلف لكل زر في أسئلة المباراة والاستراحة والماء |

## هيكل المشروع

```
app/src/main/
├── AndroidManifest.xml
├── java/com/pixelpet/app/
│   ├── MainActivity.kt          الشاشة الرئيسية (الإذن، تشغيل/إيقاف، الحركة التلقائية، السرعة)
│   ├── FloatingPetService.kt    الخدمة الأمامية + نافذة الـ Overlay + آلة الحالات والحركة
│   ├── PixelPetView.kt          Custom View: الرسم، فقاعة الحوار (RTL)، اللمس
│   ├── PetState.kt              الحالات الـ 50 كاملة (نص عربي، وجه، غرض، مؤثر، مدة)
│   ├── PetPose.kt               الرسوم المتحركة: وضعية الشخصية لكل حالة عبر الزمن
│   ├── PetRenderer.kt           رسم الشخصية بالبكسل (قبعة، نظارات، وشاح أحمر، معطف بني)
│   ├── PetProps.kt              الأغراض (سرير، لابتوب، رجل ثلج...) والمؤثرات (z z z، قلوب...)
│   └── Prefs.kt                 الإعدادات المحفوظة
└── res/ (ألوان، نصوص عربية، ثيم، أيقونة، تخطيط)
```

## الحالات الـ 50

| المجموعة | الأرقام |
|---|---|
| المشي والتنقل | 1 – 8 |
| النوم والاستيقاظ | 9 – 15 |
| العمل والدراسة والتقنية | 16 – 24 |
| الشتاء والثلج | 25 – 31 |
| الطعام والشراب | 32 – 37 |
| المشاعر والتعبيرات | 38 – 44 |
| أسئلة (نعم/لا) وأنشطة مرحة | 45 – 50 |

كل حالة معرّفة في `PetState.kt` بسطر واحد (الرقم، الجملة العربية، الرسم المتحرك، الوجه، الغرض، المؤثر، المدة). لإضافة حركة جديدة أضف سطراً هناك وحالتها في `PetPose.kt`.

بعض التسلسلات المنطقية: **نعاس ← نوم على السرير ← استيقاظ**، **كابوس ← استيقاظ مفاجئ**، ولمس الشخصية النائمة يوقظها فوراً بعبارة «هاه؟! لم أكن نائماً!».

## بناء ملف APK

### الطريقة 1: تلقائياً عبر GitHub Actions (الأسهل)
1. ارفع المشروع إلى المستودع (`git push`).
2. افتح تبويب **Actions** في GitHub ← سير العمل **Build APK**. يعمل عند كل دفع أو يدوياً من *Run workflow*.
3. بعد اكتمال البناء نزّل الملف من **Artifacts** باسم `PixelPet-debug-apk`، ثم ثبّت `app-debug.apk` على هاتفك.

### الطريقة 2: Android Studio
1. افتح Android Studio ← **Open** ← اختر مجلد المشروع، وانتظر مزامنة Gradle.
2. **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**.
3. ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk`.

### الطريقة 3: سطر الأوامر
يلزم JDK 17 وAndroid SDK (`ANDROID_HOME`):

```bash
./gradlew assembleDebug
```

## الاستخدام

1. ثبّت التطبيق وافتحه.
2. اضغط **فتح إعدادات الإذن** وفعّل «الظهور فوق التطبيقات الأخرى» لتطبيق *بيكسل بت*، ثم ارجع.
3. اضغط **تشغيل الشخصية** (على أندرويد 13+ اسمح بالإشعارات ليظهر الإشعار الدائم الخفيف).
4. من الشاشة الرئيسية: فعّل/عطّل **الحركة التلقائية العشوائية** واختر **سرعة التبديل** (بطيئة/متوسطة/سريعة).
5. لإيقافها: زر **إيقاف الشخصية** أو زر «إيقاف» في الإشعار.

## ملاحظات

- إن أُغلقت الخدمة بواسطة النظام على أجهزة معينة (Xiaomi/Huawei/Oppo...) فعّل «التشغيل التلقائي» واستثنِ التطبيق من توفير البطارية.
- إذا ظهرت الفقاعة قرب أعلى الشاشة فقد تنزاح الشخصية قليلاً للأسفل لتتسع الفقاعة.
- نسخة `release` موقّعة بمفتاح debug للتجربة فقط؛ للنشر الفعلي أنشئ مفتاح توقيع خاصاً بك.
